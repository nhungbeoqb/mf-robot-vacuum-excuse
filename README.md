A robot vacuum's funniest excuse for missing a spot — one line, 84 characters: the dust it skipped is load-bearing, and touching it would collapse the whole room.

## Run it

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt` — exactly one line, nothing else.
